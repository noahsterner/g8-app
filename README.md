# Robot Controller App
A lightweight mobile application for controlling the autonomous robot and visualizing its movement.

## Features
- Connect to the robot via BLE
- Send drive commands (forward, reverse, left, right, stop)
- Start or stop autonomous mode
- View the robot’s path and avoidance events
- Open event markers to see the captured image and classification

## Requirements Covered
- User input → drive commands (#A1.1)
- Path + event visualization (#A1.2)
- Integrates with backend position, image, and classification APIs

## Project Info
- Built as part of the Autonomous Robot System
- Communicates with robot via BLE and backend via REST
- Designed to support both manual and autonomous robot operation
